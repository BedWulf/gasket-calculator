# Калькулятор раскроя прокладок — версия 7 (исходники)

## Версия 7 — сравнение схем и технологические ограничения

- В окне **«Заказной лист / разные формы»** появилась кнопка **«Сравнить схемы рядом»**. Можно просмотреть до 6 раскладок с отдельным чертежом, длиной листа, площадью отходов и процентом использования, затем выбрать нужную схему для работы и экспорта.
- Раскрываемый блок **«Технология резки и направление материала»** позволяет задать ширину реза, ось прокатки/волокон вдоль ширины X либо длины Y листа.
- **Геометрическая компенсация реза:** расчётное расстояние между контурами = зазор + ширина реза; отступ от края листа = заданный отступ + половина ширины реза. Эти условия применяются в расчёте, ручном перемещении деталей и при чтении проекта JSON.
- В быстром вводе и редакторе отдельной детали можно отметить **«Соблюдать ось X детали по направлению материала»**. Повороты ограничены 0°/180° для направления листа X либо 90°/270° для направления Y. Несовместимые условия приводят к ошибке расчёта.
- Проекты с новыми настройками сохраняются в **JSON v3**; проекты без них продолжают сохраняться в v2. Чтение v1/v2 сохранено.
- `python -m unittest discover -s tests -q` — **78 успешных автоматических тестов** в среде разработки.

**Ограничения:** расчёт использует консервативную геометрическую ширину реза и **не является** управляющей программой станка или расчётом общей линии реза. Ось материала относится к локальной оси X чертежа детали. Абсолютный математический минимум длины листа не гарантирован. Графическое окно PyQt6 и Windows EXE ещё не проверены на рабочей Windows-машине.

---

Самостоятельная Windows-программа на **Python 3.10+ / PyQt6** для оценки расхода листового материала и подбора **длины заказываемого листа, когда его ширина известна**, для смешанной партии прокладок.

**Связи с проектом складского учёта пока нет.** Сохранён существующий интерфейс для типовых форм и выбора готовых листов; новые функции находятся в отдельном окне **«Заказной лист / разные формы»**.

## Что добавлено в версии 5 — заказ материала и надёжность

- **Материал и масса.** Под раскрываемой секцией «Материал и масса» в окне
  заказного листа можно указать марку, толщину в мм и плотность в г/см³.
  Эти поля необязательные: без них программа показывает площадь, но **не
  выдумывает массу**. Расчётная масса закупаемого листа включает отходы.
- **Спецификация TXT.** После подбора листа кнопка «Спецификация TXT»
  выгружает текст UTF-8 с BOM для корректного открытия в Windows: размеры
  закупаемого листа, количество деталей, площади, отходы, параметры материала
  и массу (если указаны толщина и плотность). Спецификация — не технологическая
  карта станка и не заменяет проверку размеров мастером.
- **Оптимистичная нижняя граница длины.** Программа показывает нижний
  ориентир с учётом отступов, ограничений по ширине и допустимых поворотов.
  Это только математическая граница, а не гарантия, что в неё поместятся
  все детали. Рекомендуемая длина по-прежнему определяется раскладкой.
- **Совместимость сохранений.** Прежние задания формата JSON v1 открываются,
  новые сохраняются в v2 с дополнительными реквизитами материала. Загрузка
  валидирует геометрию, количества, кратность длины и не принимает некорректную
  раскладку.
- **Проверки.** `python -m unittest discover -s tests -q` — 62 теста.
  Дополнительно сверены три ранее сохранённых примера v1 и случайные задания.

**Расчёт массы:** лист (м²) × толщина (мм) × плотность (г/см³) даёт численно
килограммы. Плотность нужно брать из технических данных именно вашего материала,
а не предполагать автоматически. Отходы оцениваются геометрически: ширина реза
входит в заданный пользователем зазор, припуски/дефекты/направление прокатки
задавайте отдельно. Случаи с неизвестным масштабом CAD требуют контроля.

## Что изменилось в версии 4

- В окне сложной детали появился **шаг разрешённых поворотов 15°, 30°, 45° или 90°**.
  Чтобы сэкономить время, в быстром расчёте шаг остаётся 90°; выбранный
  мелкий шаг применяется в режиме «Тщательно» (до 55 деталей). Для деталей,
  которые нельзя поворачивать из-за направления волокон/прокатки, снимите
  галочку «Разрешить повороты».
- При поиске мест в **отверстиях других прокладок** добавлена проверка
  размещения около центра выреза. Например, прямоугольник 40×30 мм входит
  внутрь кольца Ø110/Ø70 мм, и оба изделия могут быть вырезаны из листа
  110×110 мм при нулевых зазорах. При ненулевом зазоре соблюдается расстояние
  между фактическими контурами.
- При загрузке старых JSON шаг поворота по умолчанию равен 45°;
  форматы проекта и результаты существующих расчётов не изменены.
- Добавлены тесты поворотов с шагом 15°, запрета поворотов, размещения в
  отверстиях и непротиворечивости стандартного и тщательного поисков.

**Ограничение:** повороты на 15° увеличивают число проверяемых сочетаний,
поэтому тщательный поиск ограничен по времени; он не доказывает глобальную
минимальность длины. Автоматически рассчитанная схема — **предложение**,
которое нужно проверить перед заказом материала.

## Основной рабочий сценарий (v3)

Этот режим рассчитан на реальную заявку: **известна ширина материала,
известны формы и количество прокладок, а длину листа надо вычислить**.
Поля «Длина листа» в задании нет — программа сама формирует рекомендуемые
размеры заказного листа **ширина × длина (мм)**.

1. В главном окне нажмите **«Заказной лист — подобрать длину»**.
2. Введите ширину поставляемого материала, зазор между деталями, отступы от
   кромок и кратность заказываемой длины (например, 10 мм).
3. В блоке **«Быстро добавить типовую деталь»** выберите прямоугольник,
   круг, кольцо или прямоугольник с закруглёнными углами. Укажите размеры
   и количество, затем нажмите **«Добавить в список»**. Ненужные для выбранной
   формы поля скрыты. Пустое название создаётся автоматически из размеров.
   Повторное добавление полностью совпадающего типоразмера объединяет строки.
4. Для нестандартной формы нажмите **«Создать сложную деталь»** (редактор
   вершин, отверстий и скруглений) или **«Импорт SVG / DXF»**. В обоих случаях
   после подтверждения деталь попадает в общий список. Выставьте количество.
5. Нажмите **«Подобрать длину листа автоматически»**. Алгоритм размещает
   **все типоразмеры совместно на одном листе** и выбирает кратную заданному
   шагу минимальную длину среди проверенных корректных раскладок.
6. Проверьте расположение и площадь отходов, при необходимости переместите
   детали вручную и сохраните JSON/SVG.

**Пример улучшения v3:** 4 круга Ø100 мм, ширина листа 250 мм, зазоры и
отступы 0 мм, шаг заказа 10 мм. Раньше рядная укладка требовала 200 мм,
теперь смещённые ряды дают **250 × 190 мм**. Размещение проверено на
взаимные пересечения, границы листа и количество деталей.

В быстром режиме круги и кольца могут размещаться смещёнными рядами.
«Тщательно» дополнительно пробует разные порядки укладки и повороты
**сложных** контуров с шагом 15°, 30°, 45° или 90° (если повороты разрешены). Для партий более
55 деталей дополнительные дорогостоящие варианты не запускаются.
**Абсолютно математический минимум длины не гарантирован:** это эвристический
поиск наиболее плотного корректного размещения. Настройте зазор с учётом
особенностей технологии резки, направления материала и допусков.

### Когда следует проверить работу программы вручную

При нестандартных прокладках, чертежах с дугами, при неизвестных единицах
DXF/SVG и при использовании минимального зазора необходимо сверить размеры
и проверить раскрой технологом до заказа материала. GUI и сборка EXE
требуют проверки на Windows; локально выполнялись тесты геометрической части.

## Режим «Заказной лист / разные формы»

1. Введите **ширину листа**, **отступ от края**, **зазор между прокладками**, **шаг длины заказа** (всё в миллиметрах).
2. Создайте или импортируйте несколько типов деталей; у каждого — своё количество. Допускаются прямоугольники, круги, кольца, прямоугольники со скруглениями, произвольные многоугольники с отверстиями.
3. Выберите качество раскроя: **«Быстро»** или **«Тщательно»**. Тщательный режим перебирает дополнительные порядки и опорные точки контуров; применяется к партиям до 55 шт. и ограничен по дополнительному времени поиска. При большей партии используются только базовые стратегии.
4. Нажмите **«Рассчитать длину и раскладку»**. Программа предложит минимальную **из найденных** длин листа, кратную заданному шагу, и покажет расположение деталей, их площадь и отходы.
5. В схеме можно перетаскивать детали мышью (с проверкой пересечений). Сохраните задание в JSON или экспортируйте схему раскроя как SVG в мм.

**Важно:** расчёт остаётся **эвристическим**. Найденная длина не является доказанным математическим оптимумом, даже при тщательном режиме. Процент отходов считается по геометрической площади; стоимость резки, потери от прогрева/реза, технологические перемычки и дефекты не учитываются автоматически.

## Редактор сложного контура

Нажмите **Добавить** → форма **«Контур с отверстиями»** → **«Нарисовать / изменить контур мышью»**.

- **Синие** вершины — внешняя граница, **оранжевые** — отверстия. Перетаскивайте их мышью или задавайте координаты X/Y точно (до 0,01 мм).
- **Двойной щелчок** возле ребра добавляет вершину; также есть кнопки «Добавить / Удалить вершину», «Отменить изменение» и привязка к сетке.
- Есть прямоугольные и круглые отверстия. Выбранный **выпуклый угол** можно скруглить по радиусу R (дуга аппроксимируется точками с малой погрешностью). Для вогнутых углов и сопряжений нескольких дуг используйте CAD-редактор и последующий импорт DXF/SVG.
- Рядом с контуром отображаются справочные размеры сторон и общих габаритов. Они не заменяют инструмент размерения в профессиональной CAD-системе.
- При подтверждении контура проверяются валидность, самопересечения и расположение отверстий. Если импортированный контур состоит более чем из 350 точек, его можно смотреть и изменять координаты, но перетаскивание всех точек отключается для быстродействия.

Редактор сохраняет контур как набор вершин: после скругления или импорта дуги остаются аппроксимированными, а не параметрическими CAD-объектами. Внутренние отверстия не учитываются как отдельные изготавливаемые прокладки: другие детали могут быть помещены внутрь них только если проверка отступов и зазора проходит.

## Импорт чертежей SVG и DXF

В окне заказного листа нажмите **«Импорт детали SVG / DXF»**. В одном файле должен быть **один внешний замкнутый контур** (в нём может быть любое количество вложенных отверстий). Несколько разных деталей нужно импортировать по отдельности, затем задать их количества.

**SVG:** поддерживаются `path` (линии, квадратичные/кубические кривые и эллиптические дуги), `polygon`, замкнутые `polyline`, `rect`, `circle`, `ellipse`, группы и основные преобразования `translate/scale/rotate/matrix`. Величины приводятся к миллиметрам по физическим `width/height`, `viewBox` и преобразованиям. Если миллиметры не заданы явно, программа просит подтвердить предположение о масштабе; не подтверждайте его без проверки в редакторе чертежей. Надписи, размеры, raster image, внешние ссылки, DTD и отдельные незамкнутые линии отклоняются.

**DXF:** читаются `LWPOLYLINE`, `POLYLINE`, `CIRCLE`, `LINE`, `ARC`, `ELLIPSE`, `SPLINE`; отдельные смежные линии и дуги собираются в замкнутые профили. Используются единицы `$INSUNITS`; если единицы неизвестны, необходимо вручную подтвердить предположение **1 единица = 1 мм**. Трёхмерные объекты, блоки, надписи, размерные сущности и произвольная сложная CAD-топология не поддерживаются. Сохраните плоскую выкройку без оформления, затем импортируйте.

Точность аппроксимации кривых при импорте по умолчанию около **0,15 мм** по локальному критерию. После импорта **сверьте известный размер** и посмотрите контур, прежде чем рассчитывать заказ. Некоторые CAD-файлы могут потребовать подготовки в исходной программе: удаления рамки листа, служебных линий, незамкнутых обводок или группировки деталей в отдельные файлы.

Примеры входных чертежей — `examples/import_example.svg` и `examples/import_example.dxf`.

## Известные технические ограничения

- Поддерживаются повороты деталей на 0°, 90°, 180° и 270°; в тщательном режиме для сложных контуров — дополнительно шаг 15°, 30°, 45° или 90°. Произвольный угол пока не поддерживается. Ограничения направления прокатки/рисунка волокон следует проверять вручную.
- Подбор заказа производится на **одном листе фиксированной ширины**. Раскрой нескольких листов, автоматический подбор ширины и учёт остатка рулона планируются отдельно.
- DXF/SVG служит для геометрического расчёта, а экспортированный SVG — для визуальной и технологической проверки, **не для отправки напрямую на станок**.
- Нельзя гарантировать сохранность проектных сопряжений и допусков в CAD: расчёт использует полигональные аппроксимации; для резки необходима проверка технологом.
- Пока нет автоматического расчёта траектории резки, времени станка, направления волокон, микроперемычек и точной ширины пропила. Зазор можно настроить вручную с учётом технологии.
- В одном задании до 300 деталей; сложные партии требуют больше времени на подбор.

## Для программистов предприятия

- `algorithms/nesting.py`: геометрическая модель, несколько стратегий раскроя, проверка коллизий и ограничений; смещённая укладка кругов.
- `algorithms/part_catalog.py`: формирование типовых деталей, проверка и объединение одинаковых строк; модуль не зависит от PyQt.
- `algorithms/import_cad.py`: импорт SVG/DXF, единицы измерения, замкнутость и контроль контуров; PyQt не требуется.
- `algorithms/contour_ops.py`: математические операции редактирования углов.
- `ui/contour_editor.py`: визуальный редактор контуров на QGraphicsView.
- `ui/order_sheet_dialog.py`: окно задания, добавление/импорт деталей, расчёт и экспорт.
- `algorithms/export_svg.py`: SVG-выгрузка раскладки; `tests/`: автоматические проверки расчёта и импорта.

Внутри логики расчёта все размеры — в мм; сериализация задания — JSON с `schema_version=1`, совместимая с исходным режимом v1. Архитектура не требует будущего объединения с учётом материалов: перенос в общую сеть или БД должен выполняться отдельным проектом.

### Альтернативные раскладки (v6)

После команды «Подобрать длину листа автоматически» программа показывает
до шести **разных, геометрически проверенных** вариантов. Первым идёт
вариант с наименьшей найденной длиной заказа. В раскрывающемся списке
показаны длина, площадь отходов и коэффициент использования листа.
Выбор варианта обновляет чертёж, данные заказа и экспортируемые файлы.

Можно вручную передвинуть детали, не нарушая отступы и зазоры: при
переключении на другой вариант ручная корректировка сохраняется в рамках
текущего сеанса. Формат JSON остался прежним: сохраняется только выбранный
вариант, а не весь набор альтернатив. Если открыть старый JSON, будет
показан один сохранённый вариант.

**Ограничение:** варианты отличаются размещением и/или длиной листа, но
получены эвристически. Первое решение лучше остальных найденных, однако
математически глобальная оптимальность не гарантирована. Все расчёты
выполняются на одном листе фиксированной ширины.

### Компактное окно подбора длины (v8)

При открытии «Заказной лист — смешанный раскрой» параметры материала, быстрый
